# 当前实现状态与后续重点

> 校对基线：提交 `478ead1`。本文件描述当前正式可达行为；历史三层技能天赋规格不作为现状。

## 当前阶段

当前局内成长由两段串行流程组成：

1. 每次升级展示三张角色构筑和一张通用祝福，四选二；每张卡可单独刷新一次；三张角色卡来自存档 `team_order` 决定的当前队伍。角色卡按 60% / 40% 发出「获得技能」卡与「技能升级卡」，旧的属性强化卡不再发牌。
2. 技能达到 5 级时，额外排队一次该技能的天赋位二选一（两个天赋位当前是占位条目）；技能达到 10 级时自动获得另一个天赋位。

每条技能线（角色特性、登场技、普通攻击、主动技能）有 1~10 级，等级保存在 `role_special_states[role_id].skill_levels`，天赋位保存在 `role_special_states[role_id].skill_talent_slots`。升级池只包含角色特性、登场技、普通攻击和所有已解锁技能，大招与未解锁技能不参与。

玩家等级达到 3 的倍数不再排队角色天赋：`pending_level_talent_choices` 已停用。`LEVEL_TALENT_DEFINITIONS` 的 70 条定义（35 个 `_1` / `_2` 互斥组）与 `has_level_talent()` 读取链保留，等待重新设计后接入新入口。

旧 18 棵技能树 / 108 节点仍留在同一脚本和历史文档中，但正式待选构建、应用、查询和存档规范化已经停用该路径：旧 `skill_talents` 会被清空，普通玩家不会因技能构筑达到 Lv.3 / Lv.6 / Lv.9 获得旧节点。

## 已具备内容

- 主菜单、存档选择、无尽模式、暂停菜单、HUD、角色面板和开发者模式。
- 三人队伍战斗：roster 现有剑士、枪手、法师、机械师四人，战斗队伍恒 3 人，由故事档 / 无尽档案的 `team_order` 决定，旧档自动兼容（部分旧文档称法师为术师）。
- 第四角色机械师：普攻“机械蜘蛛”（追踪小蜘蛛，命中即销毁）、特性“战场改装”（站场每 4 秒产 1 零件，上限 10，每个 +4% 召唤物与齐射伤害）、登场技“紧急部署”（满能切人部署 8 秒定点机炮）、大招“机械全开·郁金香齐射”（落点预警后 3 轮 300% 范围齐射），以及定点机炮、感应地雷、磁滞力场（部署力场塔、半径 450 驻留力场：减速+持续扣血；自身在力场内时加速+回血）、守卫机器人（不限时、同时最多 5 台、每台抵挡 3 次伤害后销毁）、重型炮台（大子弹）5 个全自动主动技能；所有召唤物切换角色后保留，仅在时间结束或抵挡次数耗尽时销毁。
- 营地整备台（无尽营地 `F` 交互）与主线准备界面“调整队伍”按钮共用同一换人面板：左列当前队伍、右列候补，确认后写入对应存档 `team_order`，下一局生效；队伍恒 3 人且不重复，非法操作拒绝。
- 自动攻击 / 鼠标跟随攻击模式、普攻、切人、大招和技能冷却栏。
- 每角色独立切换能量：离场角色满能切换时消耗其能量并触发新角色登场技；未满仍可切换但不触发登场技。基础切换冷却下限 0.5 秒，切换无敌 0.1 秒，退场技全局停用。
- 明确设计的后台天赋、持续效果和资源转移；周期性后台普攻调度停用。
- 普通四选二、单卡刷新、获得技能卡与技能升级卡、7 种正式通用祝福。属性构筑卡定义与数值 getter 仍在源码中，但不再发牌；祝福配方/进化代码仍在，但所需 legacy 材料不由正式奖励生成器发出。
- 技能等级（1~10 级）、5 级天赋位二选一、10 级自动补齐另一个天赋位，以及继续游戏恢复。角色天赋（`LEVEL_TALENT_DEFINITIONS`）的入口当前停用，效果代码保留。
- 角色面板“技能构筑 / 祝福账本”双页签：技能等级与天赋位状态、角色/技能绑定祝福 I—IV、实时属性、阮石和普通装备。当前不展示等级天赋账本。
- 小 Boss 装备奖励、装备持有和角色间转赠。
- 无尽 N1→N∞：每层 Lv.1 重开，`12:00` 最终 Boss 到场，击败后结算返营；生命/伤害继续线性增长，其余高风险或性能轴在 N11 封顶。
- 无尽外循环：骨头即时持久化、阮狗五石永久无限升级、全队单槽换装、`run_id` 幂等奖励和同层继续档。
- 地图边界、波次警告、难度 profile、高密度性能保护、运行态批处理、性能日志和本地自动检查。
- 本地成就；Steam 适配层仍为未来工作。
- BGM 音量、静音、循环、暂停与续播；当前没有独立战斗 SFX 系统。

## 当前主要风险

1. **成长源头未收尾**：技能等级天赋、玩家等级天赋（`LEVEL_TALENT_DEFINITIONS`）和旧 108 节点共处同一模块与测试目录，名称又都使用“技能天赋”，极易被误判为同时可达的正式系统。
2. **天赋位内容为空**：技能 5 级弹出的两个天赋位当前只是占位条目，只记录选择、不带任何战斗效果；设计数值未定，玩家在 5 级与 10 级拿到的实际收益为 0。
3. **面板缺失角色天赋可读性**：角色面板展示技能等级与天赋位，但没有展示真正生效的 `level_talents`（当前入口已停用，仅开发者可授予）。
4. **属性卡定义仍在但不可达**：角色构筑的数值强化卡（63 项）保留定义、数值 getter 和测试通路，但普通玩家不再能获得；接入技能等级成长效果时必须明确这些数值是保留、迁移还是删除。
5. **半失活配方**：直接解锁卡是普通玩家当前唯一正式可达路径；配方、材料锁、技能绑定与进化 API 仍留在运行码中，但关键 legacy 材料不进正式奖励池。
6. **切人教程错误**：运行时 `EXIT_SKILLS_ENABLED=false`，但移动教学仍宣称满能切换触发退场技和登场技。
7. **切换能量归属不够显性**：能量属于各角色，切换消耗离场角色能量；HUD/教程仍可能让玩家误解为待登场角色的资源。
8. **祝福配方锁跨角色共享**：`role_recipe_locks` 不是按角色隔离；当前正式新档难以到达该路径，但恢复 legacy 发牌、开发者注入或遗留状态仍会暴露跨角色占用。
9. **大脚本与长局性能**：`player.gd`、`main.gd` 仍是高风险协调点；高密度命中、同帧刷怪和约 2 秒自动存档仍需用 p95 / p99 / max、SavePeak 和玩法等价计数验证。
10. **资源与音频未发布就绪**：BGM 和部分美术仍是占位/非商用资源，战斗 SFX 尚未建立。

详见 `KNOWN_ISSUES.md`、`11_技术债_风险点_重构建议.md` 和 `12_性能优化与验证记录.md`。

## 后续重点

1. 设计并接入技能等级效果：每级成长数值（`player_skill_level_system.apply_level_effect()`）与两个天赋位的实际效果，并决定 63 项旧数值强化卡的保留或迁移方案。
2. 决定旧 108 节点是删除、纯归档还是重新立项恢复；决定前不得把其定义、开发者入口或历史 smoke 当成当前验收依据。
3. 为角色面板增加只读角色天赋账本，直接读取 `level_talents`；同步清理“天赋树”残留提示（该入口当前已停用）。
4. 修正教程的退场技表述，并统一“离场角色满能 → 新角色登场技”的 HUD、教程和文案。
5. 将直接技能解锁卡确立为当前唯一正式规则；未单独立项恢复完整供料、绑定、锁料和进化之前，把配方标为 legacy，不再宣称双入口。
6. 确认会议反馈所指的“第二个 Boss”，再基于复现数据调整难度或高级祝福节奏。
7. 用 N1/N3/N6/N11 的通关率、死亡时间、到达等级、构筑完成度、骨头产量和五石使用率验证“`12:00` Boss 到场 → 击败结算”的完整循环。
8. 继续以 benchmark / evaluator / trace / feature flag 为证据优化大量命中、刷怪尖峰和长局保存。
9. 主线保持固定路线方向；剧情、对话和回刷收益稳定前不扩展房间分支或大规模营地经济。

## 当前开发护栏

- 基线评审（`design-reviews/2026-08-13_当前Build全景基线分析.md`）的“暂停新增成长轴、配方材料、新 Boss 框架和旧 108 恢复工作”条款仍然有效；唯一例外是第四角色机械师：经用户决策破例并已落地（roster 第四人、三人队伍换人、70 项 / 35 组等级天赋），其余冻结范围不变。
- 普通成长只有一条正式入口：普通四选二 → 必要祝福绑定 → 技能 5 级天赋位二选一。
- 主动技能正式解锁只走角色构筑卡；不得因配方 API 存在就假定 legacy 材料可由普通玩家获得。
- 技能等级与天赋位修改 `scripts/player/player_skill_level_system.gd`、对应运行时消费点与保存回归；角色天赋入口重新启用前不得写入旧 `skill_talents`。
- 旧 108 节点只能作为历史规格或显式批准的迁移项目处理，不得通过局部 UI/测试重新造成“已恢复”假象。
- 新增进度内容必须归入角色构筑、祝福、技能等级与天赋位、角色天赋（待重新设计）或装备模块。
- 新奖励流程优先进入 `scripts/game/reward_flow.gd` 和对应 player applier；新玩法不继续堆入 `player.gd` / `main.gd`。
- UI、教程、文档、存档和运行时效果必须引用同一稳定 ID 与同一当前状态。
