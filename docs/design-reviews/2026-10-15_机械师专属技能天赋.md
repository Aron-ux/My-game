# 机械师专属技能天赋

## 0. 决策摘要

机械师技能升到 5 级后原本只能选择没有效果的天赋位。按用户本轮授权设计并补齐 16 个专属效果，允许偏强，不以平衡作为验收门槛。保留 5 级先选一个、10 级获得另一个的正式成长规则。

完成条件：每个天赋可从正式入口获得、产生说明中的效果，组合与切人可用，保存恢复不重放施放、不重复加成，选卡与人物页显示真实名称和规则。实施范围见第 12 节；验证完成后更新第 16 节。

## 1. 范围与约束

目标场景是局内升级、三角色轮转和运行中继续游戏。角色方向是制造零件、铺设装置、切人后机械继续作战。先提供可观察的数量、空间、火力和维修变化，再考虑后续强度。

范围包括八条现有技能线、16 个效果、卡面/悬停/人物页、部署来源和存档回归。不增加成长轴、货币、按键、美术依赖或旧角色天赋入口。大招不进技能等级池，只间接受零件强化。数值平衡、整局难度调参、通用飞行物/大招回调序列化和集中 HUD 计数另行处理。

复用当前机炮、蜘蛛、守卫、地雷、力场与重炮资源；支持 1280×720 与 960×540 窗口检查。沿用稳定 slot ID 和已有运行档格式。

## 3. 玩家问题与成功标准

玩家应在 5 级看懂“先强化哪种作战方式”，选择后能观察到蜘蛛成群、双机部署、环形雷阵、随行力场或重炮爆炸；10 级组合两种效果。选择次序有差别，满级不永久失去另一个方向。

成功信号是卡面有真实短规则、战斗 getter 与数量/范围一致、人物页能区分已生效和未获得、旧档记录的槽位能直接获得效果。出现空收益、跨技能串用天赋、重复施放或数据丢失即为失败。更好玩是待玩家体验验证的假设，偏强不构成失败。

## 4. 状态与机制清单

| 状态域 | 所有者、变化和生命周期 |
| --- | --- |
| E 存在 | ability 持有部署实例；每次施放按天赋决定新增数量，读档只恢复保存数量 |
| K 身份/结构 | 机炮实例以 `progress_id` 区分登场与主动；蜘蛛和重炮保持原技能身份 |
| X 空间 | 地雷在 96 半径圆周布置；力场可跟随站场角色；高爆半径 140 |
| R 关系 | 守卫/力场维修当前站场角色；零件强化机械师所属装置及大招 |
| V 数值/资源 | 零件容量/产速/每件增伤改变；维修不回填格挡次数，不产生新货币 |
| C 控制 | 现有施放、自动/手动模式、切人和暂停保持；不新增操作 |
| H 信息 | 纯目录提供天赋名、短文案和详情；当前参数读运行 getter |
| Q 时间 | 射击/力场间隔实时读取；部署寿命在生成时确定，保存剩余时间 |
| P 权限 | `has_talent_slot` 是生效门禁；未拥有时维持基础规则 |
| M 决策 | 5 级先选一个；10 级自动补齐；旧角色天赋不参与此选择 |

建立数量和跟随效果，改写现有参数，转移维修目标至站场角色；不撤销旧档兼容。核心机制卡：技能达到 5 级 → 正式奖励队列二选一 → 写入对应 slot → 下一次攻击/施放或持续 getter 生效 → 卡面与人物页反馈；新局按现有规则重置，继续档保留，失效/重复选项拒绝应用。

## 5. 链、环、网络与生态

动作链：经验升级 → 技能卡 → 5 级选天赋 → 部署/走位/切人 → 装置继续工作 → 10 级组合。零件由计时生产，仍不消耗；离线工厂让切人期间也能积累，精密堆叠扩大收益。守卫把有限格挡转成保护与维修，不能靠治疗重新生成格挡。

蜂群与穿透、双联与超频、集束与高爆、快跳与随行可叠加。爆炸只结算一次附加范围伤害，不递归生成炮弹或再次爆炸。敌群形状会影响穿透和范围的价值；与其他角色的具体最优轮转是待实玩验证的假设。

## 8. 整局生命周期

| 阶段 | 目标和边界 |
| --- | --- |
| 进入前 | 不增加配置；机械师加入三人队伍后使用现有成长入口 |
| 前 30 秒 / 0—3 分钟 | 未获天赋时保持原规则；已获天赋按槽位生效，不按玩家等级触发 |
| 3 分钟小 Boss / 3—6 分钟 / 6 分钟强袭 | 原奖励、时间和敌群不变；5 级技能获得可见变化 |
| 6—9 分钟 / 9 分钟小 Boss / 9—12 分钟 | 10 级组合两个方向，原有部署不会凭升级回填寿命/次数 |
| 最终 Boss | 保持 12:00 到场和击败结算；本轮不以通关速度作为平衡约束 |
| 结算/死亡 | 原重试与奖励所有者保持；死亡停止零件生产 |
| 营地/重试/继续档 | 新局按原规则重置；继续档恢复，不重放施放和即时治疗 |

## 9. 退化模式与边界

偏强、单一最优解和角色输出占比不作为本轮阻塞。必须排除无效选择、跨来源串用、保存重复加成、恢复额外召唤、爆炸递归和对象池串效果。局内成长仍有上限，不新增永久成长。

暂停由既有场景/奖励调度停止模拟；查看详情不触发技能。移动力场同步中心与画面，耗尽后清理；长帧只结算有效剩余时长。额外蜘蛛/炮弹为固定数量；密集战斗 p95/p99、闪烁舒适度及长期资源压力没有本轮证据。沿用资产，无新增授权或发布假设。

## 10. 综合发现

| 优先级 | 断点与处理 |
| --- | --- |
| P1 | 槽位保存成功但没有收益 → 运行时消费同一 slot 所有权 |
| P1 | 相同机炮对象可能混用天赋 → 按每座 `progress_id` 读取射速、弹数与时长 |
| P1 | 多机效果可能在读档重放 → 恢复实例只调用单实例生成，数量取保存数组 |
| P2 | 卡牌渲染器写死“尚未实装” → 按正式载荷展示，人物页读取同一纯目录 |
| P2 | 高爆复用旧分裂弹会受画面预算吞伤害 → 单独一次性命中爆炸，预算只管视觉 |

根因链：成长记录与运行消费、显示目录脱节 → 玩家选到空条目 → 本轮把三者接在现有槽位合同上，避免新增第二套状态。

## 11. 方案比较

| 方案 | 玩家价值/成本/风险 | 决定 |
| --- | --- | --- |
| 保持占位 | 无新增成本，仍有空选择，不能完成用户要求 | 否决 |
| 每槽统一加伤 | 成本低，八条技能差异不足，缺少可见玩法变化 | 否决 |
| 16 个适配各对象的效果 | 有数量、空间、控制、生产与维修变化；需覆盖组合和保存 | 采用 |

沿用既有角色与 ability 所有者，只有高爆在通用 bullet 增加一个默认关闭、重置时清空的参数；无需新事件总线或额外施放系统。

## 12. 决定与设计合同

决定：在本轮授权下实施。完整数值表见 [当前战斗文档的机械师天赋](../03_战斗系统与角色机制.md#机械师专属技能天赋)，名称、短文案与参数常量在 `mechanic_skill_talent_catalog.gd`。

- 前置/权限：拥有该机械师技能槽位；5 级选择一个，10 级获得另一个。不改变技能解锁条件、冷却和成本。
- 两个槽可组合；其他角色不继承机械师效果。未获得时不生效；旧档中已授予的机械师槽位直接启用对应效果。
- 登场机炮和主动机炮分别读自己的槽位。新数量/寿命用于后续部署；已在场对象的射速、伤害、地雷范围、力场频率/跟随即时读取，不续命、不补次数。
- 每次蜂群属于同一次普攻；穿透遵循现有同敌去重。高爆每发首次命中附加一次等额范围伤害，包含主目标，不递归；特效预算只影响画面。
- 守卫每次实际格挡维修当前角色，最后一次也有效；治疗不返还格挡。力场切人后跟随当前角色，保存计时，恢复不补跳。
- 零件仍不消耗；后台生产是明确的待命天赋，不恢复待命角色周期普攻。
- 反馈：卡面两行核心规则，悬停完整说明，人物页实名与拥有状态，HUD 读取实值并列出已生效天赋；沿用现有声音/特效/镜头规则。
- 数据：沿用 `skill_talent_slots` 和 `skill_level_talent:mechanic:<progress>:<slot>`；不写旧 `level_talents`，不启用旧队列。局内清理/永久保存边界不变；开发者旧天赋仍是另一条兼容路径。
- 回滚条件：错来源、重复恢复、无效选择或对象池串效果；暂缓以强度为由回滚。

## 13. 验证计划

假设：可见数量、跟随和爆炸变化会让玩家更容易感知成长；需要后续实玩评价，自动检查只能验证规则。

验收包括 16 个正式选择、两种选择次序、10 级补齐、重复选择拒绝、只读预览；逐项战斗组合、切人、时长边界；JSON 保存/反复恢复、剩余时间/数量/格挡不回填；对象池清空高爆；预算耗尽保留伤害；1280/960 的两张天赋卡和人物页。执行项目完整检查，不执行平衡调参或长局 benchmark。
