# survivor-like 文档索引

`01`—`12` 主要记录当前项目状态：普通升级为“三张角色构筑 + 一张通用祝福，四选二”；单个技能构筑在 Lv.3 / Lv.6 / Lv.9 依次追加三阶段二选一天赋。`13`、`14` 和根目录 `ROADMAP.md` 记录已实施的 108 节点规则、验证边界与后续目标；其中 144 路径行为回归和数值平衡仍未完成。

根目录 `PRODUCT.md` 与 `DESIGN.md` 分别记录产品目标、反例边界和当前暗金“构筑档案”视觉系统；实现新 UI 前应先保持这两份约束一致。

## 使用建议

- 查项目怎么跑：看 `02` 和根目录 `README.md`。
- 查战斗现在怎么工作：看 `03`。
- 查升级、祝福、技能解锁：看 `04`。
- 查关卡、Boss、难度：看 `05`。
- 查 UI、角色面板、存档、音频：看 `06`。
- 查当前进度和下一步：看 `08`。
- 查会议目标、三层 `221` 天赋和延期/否决项：看 `13` 与根目录 `ROADMAP.md`。
- 查三角色全部 108 个节点、命名和质变后升级：看 `14`。
- 查性能优化、掉帧原因和验证方式：看 `12`。
- 查代码职责和数据流：看 `09`。
