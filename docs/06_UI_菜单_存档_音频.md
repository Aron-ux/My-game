# UI、菜单、存档与音频

## 主菜单

主菜单场景：
`res://scenes/main_menu.tscn`

当前主菜单功能：

- 继续游戏
- 主线模式
- 挑战模式（当前禁用）
- 无尽模式（当前已启用，进入 `res://scenes/endless_save_select.tscn`）
- 开发者模式
- 设置
- 退出

## 主菜单视觉规则

- 当前首屏即主菜单
- 背景图需要随窗口和全屏自适应拉伸
- 当前主菜单背景资源来自 `assets/demo2.png`

## 设置菜单

主菜单和暂停菜单都支持：

- 背景音乐音量滑条
- 背景音乐静音开关
- 性能日志记录开关（默认关闭，仅用于短时间排查卡顿）
- HUD 布局选择：默认“旧版：底部技能栏”，可切换到“新版：三行队伍状态带”

主菜单设置面板实现：

- `scripts/main_menu.gd` 点击“设置”后调用 `settings_panel.open()`。
- `scripts/ui/main_menu/main_menu_settings_panel.gd` 根节点必须是全屏 `Control`，不能再依赖 `CenterContainer` 居中。
- 设置面板内部使用 `scripts/ui/core/survivors_modal.gd` 统一弹窗；打开和窗口尺寸变化时会重新 `apply_layout()`，保证弹窗居中且不贴角落。


## 显示设置

当前主菜单设置面板包含显示设置页：

- 窗口模式：窗口 / 全屏
- 窗口大小：`1280x720`、`1600x900`、`1920x1080`
- HUD 布局：旧版底部技能栏 / 新版三行队伍状态带
- 窗口可拖拽调整，`WindowDisplayManager` 会将窗口尺寸校正为 `16:9`
- 项目默认使用 `canvas_items + keep`，避免非标准比例下画面被拉伸变形
- `project.godot` 显式启用 `window/size/resizable=true` 和 `window/stretch/aspect="keep"`，本地检查会校验这些显示配置。
- `project.godot` 显式设置 `run/max_fps=120` 且关闭 VSync 帧率钳制，避免渲染被固定在 60 FPS，同时把最高渲染帧率限制在 120 FPS；物理 tick 仍按 Godot 默认 60Hz 运行。
- 显示设置保存于 `user://settings.cfg` 的 `display` section
- 性能日志记录设置保存于 `user://settings.cfg` 的 `gameplay/performance_trace_enabled`；开启后写入 `user://performance_trace_latest.jsonl`，包含周期样本和慢帧样本。
- HUD 布局设置保存于 `user://settings.cfg` 的 `gameplay/hud_layout`；默认值为 `legacy`。

## HUD

当前 HUD 方向：

- 常驻显示：时间、等级
- 核心显示：经验条、HP、MP / 大招能量
- Boss 出现时顶部切换为 Boss 名和 Boss 血条
- 默认底部战斗栏采用旧版居中布局：左侧为 `Q/E` 轮换头像和切换冷却，中间为固定 6 格技能冷却槽，右侧为当前角色大招能量；经验条与 buff 栏保留在技能槽附近。
- 可在设置中切换到新版横向三行队伍状态带：上行为 `Q` 上一位，中行为当前站场角色，下行为 `E` 下一位；每行同时显示角色 HP、MP / 大招能量和固定 6 个技能冷却槽，未解锁槽位保留空格。
- 新版布局中当前站场角色固定在中间，并通过更高行高、暗金边框、左侧发光竖线、整体右移和更亮技能格强调；待命角色保持较小尺寸和低亮度。
- 战斗栏上方的 buff 栏会显示临时状态；剑士登场后的“嗜血”使用蓝底单字“嗜”图标显示剩余时间
- 技能/普攻图标使用短标签保持 6 格技能栏比例；剩余冷却、完整技能名和说明放在鼠标悬停详情中，空槽悬停时显示预留说明。
- 技能每完成一个天赋阶段后，完整名称按顺序追加节点名，技能栏使用最后节点名的前 2 个汉字；悬停详情保留完整名称、路径和全部已选阶段机制。轻量帧刷新只更新短名称，不重复重建长说明。
- 角色行悬停时显示该角色 HP、MP / 大招能量、切换能量和切换冷却，技能格悬停时显示对应角色的技能说明和剩余冷却。
- 右下角显示小地图，包含玩家、敌人、Boss、经验晶体和回复道具位置
- 战斗栏表现刷新以 30 FPS 为目标，覆盖时间、切人冷却、技能冷却、大招能量和小地图位置刷新。
- 战斗地图边界在世界空间以蓝色边框显示，玩家不能越过边界
- 高级信息可通过按键切换显示
- 开发者性能信息包含 FPS、帧时间 p95 / p99 / max、自动存档 SavePeak、运行时实体计数、新怪入场队列 SpawnQ、保存峰值规模、敌人/敌方弹幕/掉落物批处理状态与峰值计数，便于在高密度战斗或长时间游玩中对比优化效果；开启“记录性能日志”后会额外把周期样本和 `>=33.4ms` 慢帧样本写入 JSONL 日志。

## 营地交互与对话

- 无尽营地场景为 `res://scenes/endless_camp.tscn`，统一使用设置中的“交互”按键，默认是 `F`。
- `阮狗` 位于传送门左侧；玩家进入它朝向前方的交互区后显示“和阮狗说话”提示。
- 对话打开时停止营地角色移动；按交互键推进台词，最后一句后进入五张固定石头卡的收藏面板，或随时按 `Esc` 关闭。
- 对话框复用营地暗金面板样式，并显示 `阮狗` 的 CC0 像素画头像。
- 石头面板显示当前骨头、已装备石头、五石当前/下一级效果与费用。已拥有石头可免费装备；获取或升级按 `5 + 当前等级 × 3` 扣除骨头。

## 角色面板 / 构筑档案

触发方式：`C`。面板打开时暂停战斗，关闭后按当前奖励、暂停或游戏结束状态恢复暂停规则。

当前角色面板采用“构筑档案”布局：

- 顶部显示当前查看角色、战斗暂停状态和关闭提示。
- 左侧竖向队伍卡展示三角色，点击可切换查看对象，并区分当前站场与待命角色。
- 中央区域展示当前角色移动像素图、定位标签、核心属性和装备槽。像素图来自 `assets/players/*/*-run.png` 的运行帧，并叠加暗金画像纹章背景；属性为战斗中实时生效值。
- 装备行首项为全队共享且不可赠与的阮石槽；其余普通装备保留右键赠与交互，可把当前角色持有道具赠与其他角色。
- 右侧为单一“战斗档案”工作区，通过 `技能构筑 / 祝福账本` 双页签切换；默认打开技能构筑页，`Ctrl+Tab` 可切页，普通 `Tab` 保留焦点导航，页签显示当前条目数。
- 技能构筑页左侧固定列出特性、登场技、普攻、两个主动技能和终结技共 6 个选择器；鼠标指向、键盘聚焦或点击任一技能，右侧立即切换到该技能的固定三阶段左右树。
- 三阶段树显示阶段 I/II/III 的左右节点、已选择/本局未选/待选择/技能锁定状态，以及对应的构筑 Lv.3 / Lv.6 / Lv.9 门槛；路径显示为 `---`—`222`。
- 树下方独立展示具体普通构筑、重复次数和当前天赋的后续升级说明；普通构筑仍不画成天赋节点。
- 祝福账本按“团队共享角色祝福 / 技能绑定祝福”分组，完整显示已持有的 I—IV 各阶次数、最高已持有阶效果和实际作用域；角色祝福对三人共同生效，技能祝福按连段、持续、数量或魔石技能类型生效，点击后展开各阶效果及技能关联。
- 祝福各阶独立持有，角色面板只查看当前状态，不提供合成或其他操作入口。
- 两页都保留教学型空状态；切换查看角色不会改变当前站场角色。

## 地图边界与小地图

当前战斗地图范围由 `scripts/main.gd` 的 `map_bounds` 导出属性控制，默认：

```gdscript
Rect2(Vector2(-1600.0, -900.0), Vector2(3200.0, 1800.0))
```

职责分配：

- `scripts/game/game_map_flow.gd`：创建地图边界显示，收集小地图位置数据
- `scripts/map/map_boundary_view.gd`：绘制世界空间边界框
- `scripts/player/player_map_bounds_flow.gd`：玩家移动后钳制在地图范围内
- `scripts/hud.gd`：绘制右下角小地图

小地图颜色约定：

- 青色：玩家
- 红色：普通敌人 / Boss
- 黄色：精英
- 粉色：小 Boss
- 绿色：经验晶体
- 粉红：回复道具

## 暂停菜单

触发方式：`ESC`

当前暂停菜单功能：

- 继续游戏
- 重新开始
- 无尽模式可选择“结束本轮并返回营地”；确认后清除当前战斗存档，永久骨头与阮石档案不受影响
- 返回主菜单
- 音量调节
- 静音开关
- 性能日志记录开关

## 性能日志

- 开关入口：主菜单设置或暂停菜单的“记录性能日志”。
- 默认关闭，建议只在复现卡顿前开启，复现几秒后关闭。
- 日志路径：`user://performance_trace_latest.jsonl`，每次重新开始记录会覆盖上一份。
- 每行是一个 JSON 对象；`reason=periodic` 是固定间隔样本，`reason=slow_frame` 是单帧耗时不低于 `33.4ms` 的慢帧样本。
- 样本包含：FPS、`delta_ms`、生存时间、实体计数、待刷怪队列、批处理状态、帧时间分位数、当前帧/峰值 counters、SavePeak 和性能 feature flags。

## 存档结构

核心脚本：
`scripts/save_manager.gd`

存档根目录：
`user://story_slots`

当前存档结构：

- `meta.json`
  记录最近使用的存档位等元信息

- `slot_x/story_profile.json`
  主线存档资料

- `slot_x/run_save.json`
  战斗中的继续存档

- `slot_x/run_save_backup.json`
  战斗存档备份

自动存档性能验证：

- 正常战斗会按 `scripts/main.gd` 的 `autosave_interval` 周期自动写入，当前默认约 2 秒一次。
- 升级、祝福绑定和技能奖励确认后的补充保存会延后到后续帧，与 HUD 完整刷新合并调度，避免奖励点击同一帧同时承担发牌、应用奖励、完整 HUD 文案重建和保存写入。
- 战斗存档固定覆盖当前存档位的 `run_save.json` 和 `run_save_backup.json`，不会按时间追加历史快照，因此磁盘文件数量不会随游玩时间增长。
- 战斗存档内容包括生存时间、BGM 播放位置、已刷精英/小 Boss/Boss 计数、Boss 击败计数、玩家运行态，以及当前敌人、敌方弹幕、经验晶体、回复道具和未拾取骨头的运行态数组。
- 无尽档案 `endless_profile.json` 持久化 `bones`、五种 `ruan_stone_levels` 和唯一的 `equipped_ruan_stone`。旧无尽档案读取时自动补齐为 0 骨头、全 0 级和未装备。
- 已停用的开局英雄特性选择不再写入 `opening_trait_choice_completed`；旧存档中的该字段会被直接忽略，不影响其余运行态读取。
- 活动技能天赋菜单不会重复增加普通 `pending_level_ups`；已选天赋以每技能有序阶段 ID 数组保存在角色特殊状态中，继续游戏时按固定角色/技能/阶段顺序重新派生并打开最早待选阶段。
- 天赋后的显示名、路径和升级文案由稳定 ID 与有序 `talent_ids` 动态投影，不新增显示名或路径专属卡池存档字段；旧存档的单个 `talent_id` 自动迁移为阶段 I。
- 运行存档以 `ability_runtime` 保存六个技能 ID：`blade_storm`、`crescent_wave`、`infinite_reload`、`shrapnel_field`、`meta_field`、`surging_wave`；读取时仍兼容旧扁平字段。
- 六个能力都保存本次施放的天赋快照。剑刃风暴、无限装填和梅塔领域恢复计数与活动实例状态；月牙剑气弹体与散弹场按已序列化状态重建。
- 限制：现有通用玩家 `Bullet` 实例和已排队但尚未执行的 scheduler 回调不跨存档。因此，读档会丢失仍在飞行的潮涌波，以及尚未执行的延迟回调；这不是已恢复的能力实例的一部分。
- 性能面板会显示 `SavePeak` 与保存峰值规模（敌人、敌方弹幕、经验晶体、回复道具、payload KB），用于排查“玩着玩着开始掉帧”的存档尖峰。
- 自动化验证仍可通过性能 feature flag `disable_autosave` 做无 UI 对照；例如设置环境变量 `MY_GAME_PERF_DISABLE_AUTOSAVE=1` 后运行游戏，可临时跳过周期性自动存档。默认不开启该开关，不改变正式玩法。

## 当前存档位规则

- 当前固定 `3` 个故事存档位
- 每个存档位相互独立
- 继续游戏默认基于最近使用的存档位

## 继续游戏规则

- 强退或中途返回主菜单后，允许继续当前战斗
- 继续目标通常回到 `main.tscn`
- 无尽档存在进行中的战斗时，选档会直接续战，不再先进入营地
- 无尽 Boss 奖励链结束后选择返营会保留战斗存档；营地传送门继续原局
- Boss 奖励与“继续深入 / 返回营地”选择完成前不覆盖上一份安全战斗快照；开发者模式不读取、写入或清除正式战斗存档
- 无尽模式死亡或确认“结束本轮并返回营地”会清除战斗存档，但保留永久骨头与阮石
- 如果没有战斗存档但有主线存档，则回到主线准备流程

## 通用 UI 组件

本轮 UI 重构抽出了这些通用组件：

- `scripts/ui/theme/survivors_ui_theme.gd`：幸存者风格颜色、按钮、卡片、字体缩放、弹窗尺寸常量。
- `scripts/ui/core/survivors_modal.gd`：全屏遮罩 + 居中弹窗，支持按窗口比例和最大/最小尺寸自适应。
- `scripts/ui/components/survivors_card_list.gd`：带常显滚动条的卡牌列表 / 网格。
- `scripts/ui/components/survivors_hover_detail.gd`：悬停详情浮层，按内容自动估算尺寸，避免重复追加三英雄数值段落。
- `scripts/ui/components/survivors_slot_card_factory.gd`：存档位、难度等奖励卡片样式工厂。
- `scripts/game/blessing_unlock_notice_flow.gd`：祝福材料被技能解锁/进化配方锁定时的战斗内短暂提示弹窗。

交接原则：阻塞式选择弹窗优先复用 `SurvivorsModal`；战斗内短提示可复用 `SurvivorsTheme` 生成轻量弹窗；新增卡牌列表优先复用 `SurvivorsCardList`，不要重新写一套固定像素弹窗。
