# 主线流程与数据结构现状

## 一、主线模式当前骨架

当前主线流程已经具备最小可用骨架：

1. 主菜单
2. 存档位选择
3. 主线准备界面
4. 进入战斗
5. 战斗结束后回到主线推进

## 二、当前主线数据来源

核心脚本：
`scripts/story_data.gd`

当前提供的数据包括：

- `PREP_SCENE_PATH`
- `BATTLE_SCENE_PATH`
- `SAVE_SELECT_SCENE_PATH`
- `ROLE_POOL`
- `STORY_STAGES`
- `ROLE_STYLES`

## 三、角色池现状

当前角色池为：

- 剑士 `swordsman`
- 枪手 `gunner`
- 法师 `mage`
- 预留角色4
- 预留角色5

当前前三位为可用角色，后两位仍为预留占位。

## 四、关卡表现状

当前 `STORY_STAGES` 已定义了 3 个主线关卡：

1. 第一章·前哨清剿
   标准战斗关

2. 第一章·裂隙推进
   强化普通关

3. 第一章·星核讨伐
   Boss 关，击败后获得 Boss 核心材料

## 五、故事档当前结构

默认故事档大致包含：

- `slot_id`
- `chapter_index`
- `current_stage_index`
- `boss_core_fragments`
- `unlocked_role_ids`
- `team_order`
- `created_unix`
- `last_updated_unix`

## 六、主线准备界面现状

核心脚本：
`scripts/story_prep.gd`

当前可做的事情：

- 查看当前主线进度
- 查看和调整队伍顺序
- 进入下一关

## 七、主线系统当前意义

当前主线系统还不是完整剧情模式

它更像一个已经落地的骨架，用来承载：

- 存档位
- 队伍编成
- 关卡推进
- Boss 材料累积

## 八、无尽营地当前交互

- 无尽模式已使用可移动营地场景 `res://scenes/endless_camp.tscn`。
- 营地已有角色站位、铁匠、阮狗、无尽传送门、独立新手教学入口和通用 `CampInteractable` 交互链路；无尽传送门打开 N 层选择/续战面板，教学入口只进入教学确认。
- `阮狗` 已从纯对话 NPC 扩展为首个无尽外循环消耗口：对话结束后打开五石收藏面板，可用骨头永久获取、无限升级并免费切换唯一生效石头。
- 当前无尽档案保存骨头、阮石、最高通关 N 层、当前选择 N 层和最后结算 `run_id`；战斗开始时阮石读取为全队共享运行态。
- 每个 N 层从 Lv.1 开始，12:00 最终 Boss 后发放层级奖励并清除局内构筑返营；死亡或主动结束也清除本层运行档。只有强退/返回主菜单产生的同层继续档可续战。
- 普通小 Boss 装备、局内祝福和当前玩家等级天赋只在本层存在。未来营地装备若实现再进入永久档案，当前不预建字段。

## 九、后续可以自然接入的内容

在当前结构上，后续可继续接入：

- 第 4、5 个角色
- 更多角色间互动与台词
- 营地商店和其他 NPC 功能
- 特殊关卡
- 剧情段落
- 挑战模式

## 十、当前限制

- 主线准备界面还偏“功能版”
- 故事数据仍然较少
- 角色池只有 3 个真实可用角色
- 养成层和关卡层之间的长期循环还比较浅
