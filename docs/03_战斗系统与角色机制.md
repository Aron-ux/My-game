# 战斗系统与角色机制

## 基础操作

- `WASD`：移动。
- 鼠标：鼠标跟随模式下控制攻击方向。
- `TAB`：切换自动攻击 / 鼠标跟随。
- `Q` / `E`：切换上一名 / 下一名角色。
- `R`：释放当前角色大招。
- `C`：打开角色面板。
- `ESC`：暂停。

## 队伍结构

- 当前战斗固定三名角色：剑士、枪手、术师。
- 同一时间只有一名角色站场。
- 未站场角色通过后台攻击和切人收益参与战斗。
- 角色面板用于查看不同角色的数值、祝福、技能和道具。

## 三角色定位

- 剑士：近战压制、生存、范围斩击。
- 枪手：远程弹幕、持续输出、射程覆盖。
- 术师：范围轰炸、区域控制、AOE 压力。

## 战斗循环原则

- 普攻是持续输出基础。
- 切人是节奏转换和站场角色切换。
- 角色切换后提供 0.1 秒无敌时间，用于保证切换手感但不形成过长容错。
- 剑士的登场技会提供 3 秒“嗜血”：期间无敌，且剑士造成的吸血回复会同步作用到另外两名角色。
- 术师的“奥法盈余”持续 5 秒，期间获得的大招能量会同步分享给另外两名角色；自然结束时，术师会获得 3 层“奥术充能”。
- 大招是高价值资源，不应该廉价连发。
- 角色构筑和祝福共同改变角色数值、技能持续时间、技能数量、连段次数和技能状态。

## 升级构筑与技能

- 普通升级固定展示四张卡：三个队伍槽位各一张角色构筑卡，外加一张通用祝福卡，玩家选择其中两张。
- 每张展示中的卡可在当次升级单独刷新一次。
- 角色构筑卡包含角色特性、普攻、登场技、大招、技能解锁卡，以及已解锁技能的强化卡。
- 角色绑定祝福三人共用。
- 技能绑定祝福用于技能解锁和技能加成。
- 当前祝福技能会显示在底部技能栏，并有独立冷却。
- 当前源头代码同时保留角色构筑直接解锁和祝福配方解锁/进化路径；后续由源头统一规则，本地不另建第三套入口。

## 角色特性强化

独立的开局英雄特性选择入口已经停用。当前角色特性强化作为各角色自己的构筑卡进入四选二升级：

- 剑士构筑可强化战意触发、回复和骑士荣耀。
- 枪手构筑可强化猎杀安全圈、圈内外伤害和瞬杀层数收益。
- 术师构筑可强化奥法盈余、奥术充能获取和能量同步。

## 开发者模式

开发者模式用于快速验证：

- 角色升级。
- Boss / 小 Boss 生成。
- 小怪按类型批量生成；开发者面板可设置批量数，并分别生成追击、疾行、飞眼群、远程、重甲、冲锋、散弹等普通小怪。开发者批量生成不受普通敌人运行时上限限制，用于压测和复现。
- 忽略伤害。
- 无冷却。
- 性能指标。

开发者模式应继续使用当前构筑升级入口。
